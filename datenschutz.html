SmartDashboard – Studienprojekt · Stand: 19.11.2026

Daniel Düster, Student der Hochschule Emden/Leer. Kontakt über GitHub.

2. Zweck und Nutzerkreis

SmartDashboard ist eine private, nicht-kommerzielle Anwendung, die Termine und Aufgaben auf einer Wandanzeige (Raspberry Pi) darstellt. Sie wird ausschließlich vom Verantwortlichen selbst mit seinem eigenen Google-Konto genutzt.

3. Welche Daten werden verarbeitet?

  • Google Kalender: Termine (Titel, Datum, Uhrzeit) des eigenen Kontos werden gelesen und angezeigt. Auf Befehl (per Sprache oder als Text vom eigenen Handy, siehe Abschnitte 4 und 5) legt die Anwendung Termine an, verschiebt oder löscht sie. Für automatische Tests nutzt sie einen eigenen Test-Kalender.
  • Google Tasks: Aufgabenlisten, offene Aufgaben und deren Fälligkeitsdatum werden gelesen und angezeigt. Auf Befehl legt die Anwendung Aufgaben an oder hakt sie ab. Für automatische Tests nutzt sie eine eigene Test-Liste.
  • Anmelde-Token: Die von Google ausgestellten Zugangsdaten werden nur lokal auf den eigenen Geräten des Verantwortlichen gespeichert.

4. Sprachsteuerung

  • Mikrofon und Schlüsselwort: Das Mikrofon am Raspberry Pi wird dauerhaft lokal auf das Schlüsselwort „Hey Jarvis“ ausgewertet. Vorher verlässt kein Ton das Gerät; es wird nichts aufgezeichnet oder gespeichert.
  • Spracherkennung: Erst nach dem Schlüsselwort wird der folgende Satz in Text umgewandelt – vollständig lokal auf dem Raspberry Pi (Vosk). Die Tonaufnahme wird danach verworfen.
  • Auswertung des Befehls (Claude API): Der erkannte Text des Befehls zusammen mit dem aktuellen Datum und der Uhrzeit an die Claude API von Anthropic (Anthropic PBC, USA) gesendet, um daraus einen Termin oder eine Aufgabe zu erkennen bzw. zu erkennen, wonach gefragt wird. Es werden keine Tonaufnahmen und keine Kalenderinhalte übertragen. Laut Anthropic werden API-Eingaben und -Ausgaben standardmäßig nicht zum Training verwendet und innerhalb von 30 Tagen gelöscht (Ausnahmen u. a. bei Verstößen gegen die Nutzungsrichtlinien), siehe Anthropic Privacy Center.
  • Das Ergebnis (z. B. „Termin morgen 15:00 Uhr Zahnarzt“) wird anschließend über die Google-Schnittstelle im eigenen Kalender bzw. in der eigenen Aufgabenliste eingetragen.
  • Fragen: Fragen nach Wetter, Terminen oder Aufgaben (z. B. „Was steht morgen an?“) beantwortet der Raspberry Pi selbst aus den angezeigten Daten – Kalender- und Aufgabeninhalte gehen dabei nicht an Anthropic. Allgemeine Wissensfragen beantwortet die Claude API; übertragen wird dafür nur der erkannte Text der Frage.
  • Nachrichten: Bei Fragen nach aktuellen Nachrichten (z. B. „Was ist in Barßel los?“) sucht die Claude API selbst im Web und fasst die Ergebnisse zusammen. Dafür gehen der erkannte Text der Frage, eine daraus gebildete Suchanfrage und das Datum an Anthropic, das die Suche über einen Suchdienst ausführt. Kalender- und Aufgabeninhalte werden dabei nicht übertragen.
  • Sprachausgabe: Antworten werden mit der Stimme „Christoph“ von Microsoft Azure AI Speech vorgelesen (Rechenzentrumsregion „Germany West Central“). Dafür wird nur der Text der Antwort an Microsoft gesendet. Dazu gehören auch Antworten mit Inhalten aus Google Kalender oder Google Tasks (z. B. „Was steht morgen an?“ oder die Bestätigung beim Verschieben, Löschen und Abhaken) – sie werden ausschließlich übertragen, um sie dem Verantwortlichen vorzulesen. Es werden keine Tonaufnahmen übertragen. Ohne Internetverbindung wird lokal auf dem Raspberry Pi (Piper) vorgelesen. Informationen zur Datenverarbeitung: Microsoft-Datenschutzerklärung.

5. Zugriff vom eigenen Handy

  • Verbindung (Tailscale): Das Dashboard ist nicht öffentlich im Internet erreichbar. Unterwegs greift nur das eigene Handy über ein privates Netz des Dienstes Tailscale darauf zu. Die Verbindung zwischen Handy und Raspberry Pi ist Ende-zu-Ende verschlüsselt; Tailscale hat nach eigener Aussage keinen Zugriff auf die Inhalte (Termine, Aufgaben, Befehle). Tailscale verarbeitet dafür Angaben zu den Geräten (z. B. Gerätename, Betriebssystem, IP-Adresse, Zeitpunkt und Umfang der Verbindungen) sowie Name und E-Mail-Adresse des Kontos des Verantwortlichen, siehe Tailscale-Datenschutzerklärung.
  • Zertifikat: Für die verschlüsselte HTTPS-Verbindung wird ein Zertifikat ausgestellt. Dabei werden der Gerätename („smartdash“) und der Name des privaten Netzes in öffentlichen Zertifikatsverzeichnissen (Certificate Transparency) eingetragen. Darüber sind keine Inhalte erreichbar.
  • Handy-App: Das Dashboard lässt sich auf dem Handy als App ablegen. Sie speichert die zuletzt geladenen Termine, Aufgaben und Wetterdaten auf dem Handy, damit sie auch ohne Verbindung angezeigt werden.
  • Befehle als Text: Nach Anmeldung mit dem Passwort der Anwendung können vom Handy Befehle eingetippt werden („Morgen 15 Uhr Zahnarzt eintragen“). Sie werden genau wie Sprachbefehle verarbeitet: nur der Text des Befehls geht an die Claude API (Abschnitt 4), das Ergebnis wird über die Google-Schnittstelle eingetragen. Es gibt dabei keine Sprachausgabe.

6. Speicherung und Weitergabe

  • Kalender- und Aufgabendaten werden ausschließlich auf den eigenen Geräten des Verantwortlichen (Laptop, Raspberry Pi) verarbeitet und nur zur Anzeige und zum Eintragen verwendet.
  • Weitergegeben werden nur: der erkannte Text von Sprachbefehlen an Anthropic, der Text gesprochener Antworten an Microsoft zum Vorlesen (siehe Abschnitt 4), Suchanfragen für Nachrichten an Anthropic, Geräte- und Verbindungsangaben ohne Inhalte an Tailscale (siehe Abschnitt 5) und die Koordinaten des eingestellten Wetter-Ortes an den Wetterdienst Open-Meteo. Darüber hinaus findet keine Weitergabe an Dritte, kein Verkauf, keine Werbung und kein Tracking statt.
  • Die Nutzung und Übertragung von Informationen, die über Google-APIs empfangen werden, erfolgt gemäß der Google API Services User Data Policy, einschließlich der Anforderungen zur eingeschränkten Nutzung („Limited Use“). Über Google-APIs empfangene Daten werden nicht an Anthropic übertragen. An Microsoft gehen sie nur als Text einer Antwort, die dem Verantwortlichen vorgelesen wird (Sprachausgabe). Sie werden nicht zum Training von KI-Modellen verwendet.

7. Widerruf

Der Zugriff der Anwendung auf das Google-Konto kann jederzeit unter myaccount.google.com/permissions widerrufen werden. Lokal gespeicherte Token werden dann ungültig und gelöscht. Die Sprachsteuerung lässt sich jederzeit abschalten; dann wird das Mikrofon nicht mehr ausgewertet. Der Zugriff vom Handy endet, sobald die Geräte in Tailscale abgemeldet werden.

8. Änderungen

Wird die Anwendung erweitert (z. B. Spracherkennung über einen Cloud-Dienst oder Übertragung weiterer Daten an Anthropic), wird diese Erklärung vorher aktualisiert.
