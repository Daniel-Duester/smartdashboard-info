Daniel Düster, Student der Hochschule Emden/Leer. Kontakt über GitHub.

2. Zweck und Nutzerkreis

SmartDashboard ist eine private, nicht-kommerzielle Anwendung, die Termine und Aufgaben auf einer Wandanzeige (Raspberry Pi) darstellt. Sie wird ausschließlich vom Verantwortlichen selbst mit seinem eigenen Google-Konto genutzt.

3. Welche Daten werden verarbeitet?

  • Google Kalender: Termine (Titel, Datum, Uhrzeit) des eigenen Kontos – derzeit nur lesend.
  • Google Tasks: Aufgabenlisten und offene Aufgaben des eigenen Kontos – derzeit nur lesend.
  • Anmelde-Token: Die von Google ausgestellten Zugangsdaten werden nur lokal auf den eigenen Geräten des Verantwortlichen gespeichert.

4. Speicherung und Weitergabe

  • Die Daten werden ausschließlich auf den eigenen Geräten des Verantwortlichen (Laptop, Raspberry Pi) verarbeitet und nur zur Anzeige verwendet.
  • Es findet keine Weitergabe an Dritte, kein Verkauf, keine Werbung und kein Tracking statt.
  • Die Nutzung und Übertragung von Informationen, die über Google-APIs empfangen werden, erfolgt gemäß der Google API Services User Data Policy, einschließlich der Anforderungen zur eingeschränkten Nutzung („Limited Use“).

5. Widerruf

Der Zugriff der Anwendung auf das Google-Konto kann jederzeit unter myaccount.google.com/permissions widerrufen werden. Lokal gespeicherte Token werden dann ungültig und gelöscht.

6. Änderungen

Wird die Anwendung erweitert (z. B. Eintragen von Terminen per Sprachbefehl), wird diese Erklärung vorher aktualisiert.
